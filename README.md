💻 CuidaCompu

📌 Descripción del proyecto

CuidaCompu es una página web desarrollada con el objetivo de ofrecer información sobre componentes internos y externos de una computadora. Permite a los usuarios conocer diferentes piezas, consultar sus precios y agregar productos a un carrito de compras.

Este proyecto forma parte de la formación académica de Desarrollo de Software, a nivel de bachillerato.

🎯 Objetivo

Crear una página web sencilla y organizada que facilite la consulta de componentes de computadora y simule un proceso de compra en línea.

⚙️ Tecnologías utilizadas

HTML5: estructura de las páginas web.

CSS3: diseño, colores, distribución y estilos de la página.

JavaScript: funciones interactivas, búsqueda de productos y carrito de compras.

🖥️ Secciones de la página

🏠 Inicio

Presenta el nombre de CuidaCompu y una introducción a los servicios y productos que ofrece la página.

🔧 Componentes internos

Contiene información sobre componentes como:

Procesador (CPU).

Disco duro.

Tarjeta madre (Motherboard).

Fuente de poder.

Memoria RAM.

Tarjeta de video.

Tarjeta de red.

Tarjeta de sonido.

🎧 Componentes externos

Presenta diferentes dispositivos externos para el uso y cuidado de una computadora, como monitores, teclados, ratones y audífonos.

🔍 Buscador

Permite encontrar productos escribiendo su nombre en el campo de búsqueda.

🛒 Carrito de compras

Permite agregar productos, visualizar sus nombres y precios, calcular el total de la compra y vaciar el carrito.

💳 Sección de pago

Incluye una interfaz para introducir los datos necesarios para simular el proceso de compra.

📁 Estructura del proyecto

pro.html: página principal.

pro.css: estilos de la página principal.

catalogo.html: catálogo de componentes internos.

catalogo.css: estilos del catálogo interno.

catalogo2.html: catálogo de componentes externos.

catalogo2.css: estilos del catálogo externo.

busqueda.js: funciones del buscador de productos.

carrito.js: funciones del carrito de compras.

img/: carpeta que contiene las imágenes utilizadas en la página.

🚀 Cómo ejecutar el proyecto

Descargar o clonar el repositorio.

Abrir la carpeta del proyecto en Visual Studio Code.

Verificar que los archivos HTML, CSS, JavaScript y las imágenes estén organizados correctamente.

Abrir el archivo pro.html en un navegador web.

Explorar los catálogos y probar las funciones disponibles.
